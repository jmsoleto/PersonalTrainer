## REMOVED Requirements

### Requirement: Pyramids in the active plan
**Reason**: It stated that supersets are rejected at activation, which this change ends. Its pyramid behaviour moves unchanged to "Pyramid targets in the active plan".
**Migration**: None for users. Supersets are now activated as defined by the superset-blocks capability.

## ADDED Requirements

### Requirement: Pyramid targets in the active plan

Activating a plan template that contains pyramids SHALL produce sessions whose exercises carry each set's own target: reps or seconds, weight and rest. The exercise SHALL also keep a summary prescription equal to its first set, so screens that read only one prescription keep working. Plans generated by AI or imported from a file SHALL be unaffected.

#### Scenario: Activating a pyramid
- **WHEN** the user activates a plan whose day has "Press de Banca con Barra" as 12×40, 10×45, 8×50, 6×55 with 90 s rest
- **THEN** that session exercise prescribes 4 sets with those exact targets per set
